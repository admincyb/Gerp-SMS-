Step-by-Step Commands
1. Make sure you’re on the latest master

git checkout master
git pull origin master



2. Create a new branch from master and switch to it

git checkout -b new-branch-name


Example:
git checkout -b feature/login-page
✅ This creates a new branch called feature/login-page based on master and automatically checks it out.



3. See Uncommitted Changes (since last commit)

git status


4. Check your current branch
git branch

5.If you’re not on Test_branch, switch to it:

git checkout Branchname

Example - git checkout Test_branch

6. Stage your changes

Add all modified files (or specify individual ones):

git add .

7.Commit your changes
git commit -m "Your descriptive commit message here"


8. Push to Azure DevOps

git push origin Branchname
git push origin Test_branch


9.git push origin pallatecreation-change
